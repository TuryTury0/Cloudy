# Telegram and WhatsApp
- Find a chat: click the search box at the top of the chat list, type the name, open the right chat and check
  the name in the chat's header before writing.
- Click the message box at the bottom, then type. In these apps Enter SENDS the message: to write without sending,
  use type (not type_enter), and shift+enter for a new line.
- Send only when the goal says so, and ask first.
