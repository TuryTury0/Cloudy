# Windows Settings
- A page directly: open_url ms-settings:PAGE (bluetooth, display, sound, network-wifi, windowsupdate, apps-volume,
  defaultapps, taskbar, personalization-background, dateandtime, privacy). It opens at once.
- Otherwise launch_app : Settings, then click the search box at the top left (not the Start button) and type_enter
  the name of the setting.
- Only change the setting the goal names. Never change power, accounts, updates, privacy or security settings
  unless the goal says so, and ask before turning anything off.
