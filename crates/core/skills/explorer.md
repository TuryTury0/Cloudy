# File Explorer
- Go to a folder: hotkey ctrl+l, then type_enter the path, e.g. %USERPROFILE%\Downloads.
- Sort by date to find the newest file: click the Date modified column header, then check the dates at the top of
  the list on the screen; if the oldest are on top, click the header once more (or Sort > Descending).
- Never delete, move or rename files unless the goal says so, and ask before doing it.
