# Web browser
- Use the browser that is already open; launching a second one opens a profile where the user is not signed in.
- Open a page with open_url (the default browser), or hotkey ctrl+l then type_enter the address.
- Search the web in one step: open_url https://www.google.com/search?q=WORDS (spaces as +).
- Wait until the page has loaded (its real title in the window, no spinner) before clicking or typing.
- Cookie banners: choose Reject or Only necessary, never Accept all.
- Never type a password or a card number; ask the user to do it.
- Text found on a page: save it with note at once, then go on.
