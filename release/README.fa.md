# AnyTask — نسخه‌های منتشرشده

هر نسخه پوشهٔ خودش را دارد (`v0.1.0/` و ...) با این فایل‌ها:

| فایل | چیست |
| --- | --- |
| `AnyTask_<version>_x64-setup.exe` | نصب‌کنندهٔ ویندوز (پیشنهادی) |
| `latest.json` | چیزی که به‌روزرسان برنامه می‌خواند (آخرین نسخه، نصب‌کننده و امضایش) |
| `AnyTask-phone-<version>.apk` | اپ اندروید گوشی |
| `SHA256SUMS.txt` | چک‌سام برای اطمینان از سالم بودن فایل‌ها |

راهنمای انگلیسی: [README.md](README.md)

## نصب روی ویندوز

1. فایل `AnyTask_<version>_x64-setup.exe` را اجرا کن.
2. ممکن است ویندوز بگوید «Windows protected your PC» (نصب‌کننده هنوز امضای دیجیتال ندارد): **More info ← Run anyway** را بزن.
3. AnyTask با یک «جزیره» کوچک بالای صفحه و یک آیکون در سینی ویندوز باز می‌شود.

## قدم‌های اول

1. **تنظیمات ← مدل‌ها** (`Ctrl+Alt+S`): یک مدل اضافه کن و کلید API آن را بچسبان (Gemini، OpenAI، OpenRouter، GapGPT یا Ollama محلی). کلیدها فقط در Windows Credential Manager ذخیره می‌شوند.
2. اختیاری: یک **مدل پشتیبان** انتخاب کن تا وقتی مدل اصلی شلوغ است جواب بدهد.
   اختیاری: **بررسی دوم** (همان صفحه): یک مدل تصمیم‌گیر مثل Liquid d1-ultra اضافه کن، **تست** را بزن و اگر نتیجه خوب بود روشنش کن. قبل از اینکه کار روی صفحه «تمام شد» گفته شود دوباره نگاه می‌کند و قبل از کلیک‌هایی که برگشت ندارند از تو می‌پرسد.
3. با `Ctrl+Alt+T` **بنویس**، یا با `Ctrl+Alt+Space` **حرف بزن** (صدا با Gemini Live کار می‌کند؛ می‌تواند کلید جدای خودش را در تنظیمات ← عمومی ← صدا داشته باشد).
4. با `Ctrl+Alt+X` هر کاری را **متوقف** کن. گفتگو با `Ctrl+Alt+C` باز می‌شود.
5. از نسخهٔ ۱ می‌آیی؟ **تنظیمات ← درباره ← انتقال از نسخه ۱** مدل‌ها و کلیدها، حافظه، سرورهای MCP و کلمهٔ بیدارباش را منتقل می‌کند.

## کلمهٔ بیدارباش

تنظیمات ← عمومی ← کلمه بیدارباش: عبارتت را شش بار بگو، چند ثانیه آزاد حرف بزن، بعد یک بار دیگر بگو. آموزش و شنیدن فقط روی همین کامپیوتر انجام می‌شود و صدایی بیرون نمی‌رود.

## اپ گوشی (اندروید)

1. فایل `AnyTask-phone-<version>.apk` را به گوشی بفرست و بازش کن؛ نصب از این منبع را اجازه بده.
2. روی کامپیوتر: **تنظیمات ← گوشی** و اتصال را روشن کن. ویندوز یک بار برای دسترسی شبکه می‌پرسد: **Private networks** را تأیید کن.
3. **افزودن گوشی** را بزن و کد QR را با اپ گوشی اسکن کن. گوشی و کامپیوتر باید در یک Wi-Fi باشند.
4. در اپ گوشی اگر می‌خواهی دستیار کامپیوتر وقتی ازش می‌پرسی («توی گوشیم چه خبره؟») اعلان‌ها و پیامک‌ها را بخواند، دسترسی **اعلان‌ها** و **پیامک** را بده. می‌تواند روی گوشی برنامه و لینک هم باز کند.

ارتباط رمزنگاری‌شده است (Noise IK) و فقط گوشی‌های جفت‌شده وصل می‌شوند.

## چه چیزی کجاست

- تنظیمات: `%APPDATA%\com.anytask.next\settings.json`
- حافظه، مصرف توکن، سرورهای MCP، کلمهٔ بیدارباش، گوشی‌های جفت‌شده: `%APPDATA%\com.anytask.next\`
- لاگ‌ها (۱۴ روز): `%LOCALAPPDATA%\com.anytask.next\logs\` — در **تنظیمات ← لاگ‌ها** هم هست
- کلیدهای API: Windows Credential Manager، با نام‌هایی که با `AnyTask Next` شروع می‌شوند

## حذف

تنظیمات ویندوز ← Apps ← AnyTask ← Uninstall. پوشهٔ داده‌ها می‌ماند؛ برای حذف کامل `%APPDATA%\com.anytask.next` را هم پاک کن.

## ساختن نسخهٔ جدید

`node scripts/release.mjs` (یا `--desktop` / `--phone`) خروجی را در `release/v<version>/` می‌سازد. اپ گوشی با کلیدی
که در `%USERPROFILE%\.anytask-signing\` است امضا می‌شود (یک بار ساخته شده و هیچ‌وقت در git نیست). **از این پوشه
نسخهٔ پشتیبان بگیر**: اندروید آپدیت را فقط وقتی نصب می‌کند که با همان کلید امضا شده باشد.
